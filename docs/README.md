# Motiva legal pages (GitHub Pages)

These files power **Terms** and **Privacy** links in the app.

## Enable hosting (one time)

1. Push this repo to GitHub (`aiflowhustle-lab/motiva`).
2. On GitHub: **Settings → Pages**.
3. **Build and deployment → Source:** Deploy from branch **`main`**, folder **`/docs`**.
4. Wait ~1–2 minutes. Pages URL: `https://aiflowhustle-lab.github.io/motiva/`

Before App Store submission, update the support email in `terms.html` and `privacy.html`.
